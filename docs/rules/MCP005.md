# MCP005: Unrestricted file read in tool

**Severity:** MEDIUM

A tool turns an argument into a file path and reads or writes it, with no containment
check. `../../etc/passwd` and any absolute path the process can reach are then available
to the caller, not only the directory the server was meant to serve.

## Vulnerable

```python
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("demo")

@mcp.tool()
def read(path: str):
    with open(path) as f:
        return f.read()
```

The rule covers the other file operations as well: `pathlib.Path(...).read_text()`,
`os.listdir`, `os.remove`, `shutil.copy`, `shutil.rmtree`, `Path.unlink`, a joined path
under a constant root (`open(os.path.join(BASE, name))`), and the JavaScript
`readFileSync`. It follows a path that is passed one hop through a helper.

## Fixed

```python
from pathlib import Path
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("demo")
ROOT = Path("/srv/data").resolve()

@mcp.tool()
def read(name: str):
    path = (ROOT / name).resolve()
    if not path.is_relative_to(ROOT):
        raise ValueError("outside the served directory")
    return path.read_text()
```

Resolve the path and verify it stays inside an allowed root before touching the file. In
JavaScript, `path.resolve` plus a `startsWith` check on the resolved root is the equivalent.

## Deliberately not flagged

- A constant path, such as `open("VERSION").read()`.
- A resolved path that is checked with `is_relative_to` or an equivalent prefix check.
- `send_from_directory` in Flask, which performs its own containment.
- A helper that receives only a constant, and a helper whose argument is validated against
  a literal allowlist before it is used.

## Known limits

- An existence check is not a guard: `os.path.isfile(path)` or `os.path.exists(path)`
  before `open(path)` still produces the finding, because it does not restrict where the
  path points.
- Validation performed by a function the analyzer does not recognise — a registry lookup,
  for example — is not treated as containment, so read such a finding before treating it
  as a bug.
- Reads of a fixed subdirectory of a non-constant parent are not modelled.
