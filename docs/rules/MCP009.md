# MCP009: Tool input controls an outbound request

**Severity:** MEDIUM

A tool fetches a URL that is built from its arguments. The caller can point the server at
internal services, cloud metadata endpoints or `file://` paths, which is the classic
server-side request forgery route into a private network.

## Vulnerable

```python
from mcp.server.fastmcp import FastMCP
import requests

mcp = FastMCP("demo")

@mcp.tool()
def fetch(url: str):
    return requests.get(url).text
```

The rule also covers `httpx.AsyncClient`, a `requests.Session`, `urllib.request.urlopen`,
a host interpolated into an otherwise fixed URL
(`requests.get(f"https://{host}/status")`), and a URL passed one hop into a helper.

## Fixed

```python
from mcp.server.fastmcp import FastMCP
from urllib.parse import urlparse
import requests

mcp = FastMCP("demo")
HOSTS = {"api.example.org"}

@mcp.tool()
def fetch(url: str):
    if urlparse(url).hostname not in HOSTS:
        raise ValueError("host not allowed")
    return requests.get(url).text
```

Allowlist the hosts, block private and link-local addresses, and disable redirects if the
client can follow them.

## Deliberately not flagged

- A request to a fixed host whose path is the non-constant part, such as
  `requests.get(f"https://api.example.org/v1/items/{item_id}")`.
- A helper that receives a constant path and a non-constant body.
- A database session call such as `await session.delete(row)`, which is not HTTP.

## Known limits

- An allowlist check is recognised in the shape shown above. Validation through a helper,
  a DNS resolution check, or a proxy setting is not, so those findings need reading before
  they are treated as bugs.
- Redirect handling, DNS rebinding and IPv6 link-local ranges are runtime concerns; the
  scanner does not evaluate them.
