# MCP001: Shell or dynamic code execution

**Severity:** HIGH when a tool argument reaches the command. MEDIUM when the command is
non-constant but not tool-controlled. Constants are ignored.

A tool can run a shell, `eval` an expression, or pick the program to run. When the
command text, or the program itself, comes from the model or the user, the caller
decides what runs on your machine.

## Vulnerable

```python
from mcp.server.fastmcp import FastMCP
import subprocess

mcp = FastMCP("demo")

@mcp.tool()
def convert(path: str):
    return subprocess.run(f"pandoc {path} -o out.pdf", shell=True, capture_output=True).stdout
```

The same HIGH finding is produced by `os.system(cmd)`, `os.popen(...)`, `eval(...)`,
`exec(...)`, a program chosen by the argument (`subprocess.run([binary, ...])`), and a
helper function that receives the argument one hop away. In JavaScript and TypeScript it
is `exec`, `eval`, `new Function`, and a shell `spawn`.

## Fixed

```python
from mcp.server.fastmcp import FastMCP
import subprocess

mcp = FastMCP("demo")
ALLOWED = {"daily", "weekly"}

@mcp.tool()
def report(name: str):
    if name not in ALLOWED:
        raise ValueError("unknown report")
    return subprocess.run(["make-report", name], capture_output=True, text=True).stdout
```

Pass an argument list instead of a shell string, and validate the argument against an
allowlist before it is used.

## Deliberately not flagged

- A constant command such as `os.system("clear")`.
- A constant program with a non-constant argument, such as
  `subprocess.run(["git", "log", ref])`.
- `shell=True` with the argument passed through `shlex.quote`.
- `execFile("ls", [dir])` in JavaScript, which takes an argument list.

## Known limits

- The analyzer follows assignments, destructuring and one hop through a helper function.
  Deeper data flow, and commands assembled in a way it does not model, can be missed.
- Validating an argument with something other than a literal allowlist — a registry
  lookup, a regex, a type check — is not recognised as a guard. Those cases are still
  reported and are usually fixed by suppressing the finding with a comment that explains
  the check.
