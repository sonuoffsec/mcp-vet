# MCP012: Hardcoded credential

**Severity:** HIGH

A password, API key, token or credentialed URL is written into source or config. Unlike
[MCP003](MCP003.md), which matches a publisher's format, this rule infers a secret from
the name the value is given and the way the value looks, so it catches in-house
credentials too.

## Vulnerable

```python
import os

DATABASE_URL = os.environ.get(
    "DATABASE_URL", "postgres://admin:{{GENERATED_PASSWORD}}@db.internal:5432/prod"
)
HEADERS = {"Authorization": "Bearer {{API_TOKEN}}"}
```

The two placeholders stand for a generated-looking literal, for example a password with
mixed case, digits and a symbol. A page in this repository must not contain a working
credential, so the literal is not written here; any real value of that shape on a
secret-named key is what the rule reports.

The rule also covers a secret-named key in a JSON or `.env`-style config, a bearer token
or JWT in code, and a credentialed URL.

## Fixed

```python
import os

DATABASE_URL = os.environ["DATABASE_URL"]
HEADERS = {"Authorization": "Bearer " + os.environ["API_TOKEN"]}
```

Remove the value from the repository, rotate it, and load it from the environment or a
secret manager.

## Deliberately not flagged

The rule is tuned to stay quiet on the many credential-shaped things that are not secret:

- Placeholders and labels: `"your-password-here"`, `"<api-key>"`, `"changeme"`,
  `"${CLIENT_SECRET}"`, `{"password": "Password"}`.
- Translated interface strings, such as `{"login.password": "Wachtwoord"}`.
- Environment-variable names and secret-file paths.
- Local development defaults such as `postgres://postgres:postgres@localhost:5432/app`.
- Lock files, test tooling config, benchmark and regression files, and values in a
  documentation comment.
- A token built from a generated prefix plus random data at runtime.

## Known limits

- It is a heuristic. A short or word-like real password is missed, and a random-looking
  constant that is not secret is reported. Suppress the second case with
  `# mcp-vet: ignore MCP012`.
- Output is masked, so the report does not copy the credential. It is still in the
  repository and its history: rotate it.
