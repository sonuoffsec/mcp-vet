# MCP014: Unpinned package launched by an MCP client config

**Severity:** MEDIUM

An MCP client config launches a package by name, so the client downloads and runs the
newest published version at every start. A compromised or hijacked release then runs with
the user's permissions, without any change on disk to notice. The same problem applies to a
container image with no tag, or with the tag `latest`.

## Vulnerable

```json
{"mcpServers": {"fs": {"command": "npx", "args": ["-y", "@modelcontextprotocol/server-filesystem", "./project"]}}}
```

```json
{"mcpServers": {"db": {"command": "docker", "args": ["run", "-i", "--rm", "mcp/postgres"]}}}
```

The rule covers `npx`, `bunx` and `pnpx`, `uvx`, `pnpm dlx` and `yarn dlx` — including a
Windows `npx.cmd` path — plus `docker` and `podman` images that carry no tag or the tag
`latest`.

## Fixed

```json
{"mcpServers": {"fs": {"command": "npx", "args": ["-y", "@modelcontextprotocol/server-filesystem@2025.8.1", "./project"]}}}
```

```json
{"mcpServers": {"db": {"command": "docker", "args": ["run", "-i", "--rm", "mcp/postgres:1.2.3"]}}}
```

Pin an exact version (`npx -y package@1.2.3`, `uvx package==1.2.3`) or an image tag, or
pin the image by digest:

```json
{"mcpServers": {"db": {"command": "docker", "args": ["run", "-i", "--rm", "mcp/postgres@sha256:4c2f8295b9c02013f9e257d079eb733b115456f59b398df3158c97dd36b4421b"]}}}
```

## Deliberately not flagged

- A pinned package or a pinned image tag.
- An image pinned by digest.
- A launcher that runs a local file, such as `node ./dist/server.js`, where there is no
  registry version to pin.

## Known limits

- The rule reads the client configuration files mcp-vet knows about. A config in a format
  or location it does not know is not scanned; see `--clients` in the README to list the
  ones it reads.
- Options that take a separate value (`-e KEY=value`, `-v host:path`, `--name x`) are
  skipped when the image is located, but a subcommand that is not `run` is not modelled.
- Pinning stops a silent upgrade, not a malicious release: the version you pin was still
  published by someone else.
