# MCP013: Obfuscated strings

**Severity:** MEDIUM

A file hides many of its own strings, usually as base64. Legitimate servers rarely do
this; obfuscation is a common way to conceal the URLs, tool names and payloads that the
next stage of an attack uses.

## Vulnerable

```python
_ENDPOINTS = [
    "aHR0cHM6Ly9hcGkuZXhhbXBsZS5vcmcvdjAvc3RhdHVz",
    "aHR0cHM6Ly9hcGkuZXhhbXBsZS5vcmcvdjEvc3RhdHVz",
    "aHR0cHM6Ly9hcGkuZXhhbXBsZS5vcmcvdjIvc3RhdHVz",
    "aHR0cHM6Ly9hcGkuZXhhbXBsZS5vcmcvdjMvc3RhdHVz",
    "aHR0cHM6Ly9hcGkuZXhhbXBsZS5vcmcvdjQvc3RhdHVz",
    "aHR0cHM6Ly9hcGkuZXhhbXBsZS5vcmcvdjUvc3RhdHVz",
    "aHR0cHM6Ly9hcGkuZXhhbXBsZS5vcmcvdjYvc3RhdHVz",
    "aHR0cHM6Ly9hcGkuZXhhbXBsZS5vcmcvdjcvc3RhdHVz",
]
```

The threshold is eight or more base64-encoded text strings in one file.

## Fixed

```python
_ENDPOINTS = [
    "https://api.example.org/v0/status",
    "https://api.example.org/v1/status",
]
```

Write the strings out. If the server has a genuine reason to encode them, say why in a
comment next to the table.

## Deliberately not flagged

- A single base64 value, such as an embedded PNG.
- A table of hex digests, such as MD5 or SHA-256 hashes: high-entropy text that is not
  base64-encoded prose.

## Known limits

- The rule counts base64 strings that decode to text. A file that builds its strings one
  at a time, or uses another encoding (hex, gzip, a custom alphabet), is not counted.
- Eight is a judgement call. A test fixture with eight legitimate base64 samples is
  reported; suppress it there and keep the samples.

## Next step

Decode the strings. If the code has no reason to hide them, treat the server as
suspicious rather than as merely untidy.
